P (Polynomial Time)

Analogy: Looking for a specific page number in a book by flipping through it one by one.

Problems that can be solved in polynomial time. For searching an unsorted array, the worst-case is `O(n)`. The time it takes grows linearly with the size of the input.

def classical_search(arr, target):
    for i in range(len(arr)):
        if arr[i] == target: return i
    return -1
×

NP (Nondeterministic Polynomial)

Analogy: Trying to crack a combination lock. Easy to check if a combination is right, but finding it by trying all combinations takes forever.

NP problems are verifiable in polynomial time, but solving them brute-force requires exploring a massive decision tree `O(2^n)`. As `n` grows, it becomes computationally impossible.

×

Quantum (Grover's Algorithm)

Analogy: Having a magic tuning fork that resonates only with the right page in the book, allowing you to skip most of the flipping.

Grover's algorithm uses quantum superposition to evaluate all entries simultaneously and amplitude amplification to make the correct answer the most probable result. It provides a quadratic speedup `O(√n)`.
